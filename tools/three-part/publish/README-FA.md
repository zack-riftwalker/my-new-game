# پکیج انتشار نسخهٔ سه‌پارتی Hollow Knight

این پوشه آمادهٔ پوش به برنچ `feature/three-part-loader` ریپوی `my-new-game` است.

## محتوا
- `parts/v1/segments/` — ۱۰۵ سگمنت (هرکدام حداکثر ۱۹ مگابایت؛ سقف سرو jsDelivr)
- `parts/v1/patch/` — ۹ فایل patch (هدرها و blocks-info هر استیج)
- `parts/v1/manifest.json` + `spec_stage1..3.json` — مانیفست و نقشهٔ اسمبل هر استیج
- `CHECKSUMS.txt` — خلاصهٔ حجم دانلود هر استیج (پارت ۱: ۲۹۸٫۷۸ مگابایت)

لودر (`index.html`) از قبل روی همان برنچ هست و لازم نیست دوباره پوش شود.

## انتشار (یک بار)
از داخل همین پوشه:
```bash
bash push_parts.sh
```
اسکریپت: ریپو را کلون می‌کند، `parts/` را اضافه و کامیت می‌کند و پوش می‌کند (~۸۳۰ مگابایت).
در پایان، آدرس تست پین‌شده با SHA کامیت را چاپ می‌کند.

## لینک تست گوشی
```
https://cdn.jsdelivr.net/gh/zack-riftwalker/my-new-game@<COMMIT_SHA>/index.html
```
نکته: jsDelivr برای برنچ کش تهاجمی دارد؛ همیشه از SHA کامل کامیت استفاده کن، نه اسم برنچ.
برای دیدن شمارندهٔ فریم حین تست، `?fps=1` به انتهای آدرس اضافه کن.

## چک‌لیست تست گوشی
۱. شروع سرد: دانلود پارت ۱ (~۲۹۹ مگابایت) با نوار پیشرفت، رسیدن به منو و شروع بازی تا King's Pass
۲. رسیدن به Dirtmouth و نشستن روی نیمکت (سیو شود)
۳. از پنل «📦 پارت‌های بازی»، دانلود پارت ۲ و ادامهٔ بازی؛ سلامت سیو بعد از ریلود
۴. بستن صفحه وسط دانلود و باز کردن دوباره (ادامه از کش)
۵. روانی بازی و نرخ فریم (با `?fps=1`) روی گوشی
