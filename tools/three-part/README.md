# نسخهٔ سه‌پارتی Hollow Knight وب — ابزارها و مستندات

این پوشه آرشیو کامل مهندسی نسخهٔ سه‌پارتی است: بازی اول فقط پارت ۱
(۲۹۸٫۷۸ مگابایت) را دانلود می‌کند و در چک‌پوینت‌ها با اجازهٔ بازیکن
پارت‌های بعدی دانلود می‌شوند؛ رندر موبایل 480p و سقف ۳۰ فریم دارد و
کنترل‌های لمسی مدرن (جوی‌استیک شناور + دکمه‌های اکشن) روی آن پیاده شده.

## فایل‌ها

- `PLAN.md` — پلن جامع + لاگ اجرایی مایلستون‌ها (M0 تا M6) با همهٔ
  اعداد و راستی‌آزمایی‌ها؛ منبع حقیقت پروژه.
- `pipeline/segment.py` — موتور سگمنت‌بندی: hk.data را به ۱۰۵ سگمنت
  استیج‌بندی‌شده + فایل‌های patch + اسپک اسمبل تبدیل می‌کند
  (بلاک‌های قفل‌شده با placeholder هم‌اندازه از نوع LZ4 صفر).
- `pipeline/assemble.py` — اسمبل آفلاین هر استیج برای راستی‌آزمایی.
- `pipeline/verify.py` / `verify_unitypy.py` — راستی‌آزمایی ساختاری
  خروجی‌ها (دایرکتوری نودها، بلاک‌ها، مسیر پارس UnityPy).
- `pipeline/reproduce_m0.py` — بازتولید اعداد پارتیشن از فایل اصلی.
- `pipeline/make_publish.py` — ساخت درخت انتشار: مانیفست با ترنسپورت
  رینجی + اسپک‌هایی با patchهای base64.
- `pipeline/loader_harness*.mjs` — هارنس‌های Node که خودِ لودر واقعی را
  علیه سرور لوکال اجرا و SHA خروجی اسمبل را با مرجع مقایسه می‌کنند.
- `publish/` — README انتشار، اسکریپت پوش مستقیم سگمنت‌ها (مسیر جایگزین)
  و خلاصهٔ حجم‌ها.
- `testsite/serve2.py` — سرور استاتیک با پشتیبانی Range برای تست لوکال.

## معماری انتشار (ترنسپورت رینجی)

سگمنت‌ها جایی آپلود نمی‌شوند: هر سگمنت یک بازهٔ پیوسته از همان
`hk.data`ای است که از قبل به‌صورت ۴۲ پارت در همین ریپو هست. لودر
(`index.html` در ریشهٔ ریپو) بازه‌های لازم هر استیج را با درخواست‌های
HTTP Range از `raw.githubusercontent.com` (با SHA پین‌شده) می‌خواند و
در Cache Storage مرورگر نگه می‌دارد. فایل‌های patch به‌صورت متن
base64 در `parts/v1/patch/` هستند و لودر آن‌ها را دیکد می‌کند.

صفحهٔ بازی به‌علت سرو `text/plain` بودن HTML در jsDelivr، از githack
rawcdn با SHA کامیت پین‌شده سرو می‌شود.
